## 二、發現問題與處理

### 🔴 高（已修）

**H1. `photo` 遊戲 QR Code 外洩 session 網址到第三方**
- 位置：`src/apps/photo/components/QRCodeModal.tsx`
- 問題：用 `https://api.qrserver.com/v1/create-qr-code/?...&data=<url>` 生成 QR，會把含 `?s=<sessionId>` 嘅 `window.location.href` 傳去外部伺服器；違反 readme A 系列（「永遠假設前端已被攻陷」「secret／識別資料唔好過第三方」）同本倉「QR Code（不依賴外部 API）」嘅既定原則（`src/components/QRCode.tsx` 已存在本地實現，PhotoApp 用錯咗）。
- 修正：改用本地 `QRCode` 組件，零外部請求；e2e 測試持續綠。

**H2. PWA 完全缺失（違反 docs/46，2026-11-12 定案，適用所有有 UI 嘅 web app）**
- 問題：`index.html` 只有 `mobile-web-app-capable` meta，冇 manifest、冇 Service Worker、冇安裝入口、冇更新流程；「加主畫面＝全螢幕＋離線可用」完全做唔到。
- 修正（全套）：
  - `public/manifest.webmanifest`（standalone、theme/background `#02133E`、4 個 icons 含 maskable）
  - `public/sw.js` — 導覽 network-first（離線回退）、靜態 stale-while-revalidate、`install` 唔無條件 `skipWaiting()`、`message SKIP_WAITING`、`activate` 清舊快取、CACHE_NAME 綁版號 `scout-system-v1.1.0`
  - `src/shared/pwa.ts` — `isStandalone()`（`display-mode: standalone` + iOS `navigator.standalone`）、`isIos()`（UA + `MacIntel`+`maxTouchPoints>1`）、`registerServiceWorker()`（只喺生產環境、`updateViaCache: 'none'`、load 後註冊）
  - `src/components/InstallButton.tsx` — 右下角浮動「📲 加入主畫面」（`aria-label`、可鍵盤 focus、standalone 自動隱藏、可一鍵收起；Android 攔 `beforeinstallprompt`；iOS 出三步教學卡：Esc／背景／「知道了」都可關；`appinstalled` 後收掣＋toast）
  - `src/components/UpdateBanner.tsx` — 全域「有新版本」橫額（`role="region"` `aria-label="版本更新"`）；「稍後」記住同一 worker（module 級）；「立即更新」→ `SKIP_WAITING` → `controllerchange` → reload，3 秒 fallback；檢查時機 = `visibilitychange`／`focus`／`online`／每 30 分鐘 `reg.update()`；文案寫明本機資料保留（本 app 無連線房間，UP5 多人斷線句不適用）
- **未完成（要人手）**：I7 真機驗收（Android Chrome ＋ iOS Safari 各一次：安裝 → 主畫面開 → 斷網開）；Vercel 生產部署後實測 SW 註冊與更新流程。

**H3. G11 全站圖標標準不符（定案 2026-10-28）**
- 問題：只有 inline SVG ⚜ data-URI favicon；冇 ICO、冇 apple-touch-icon、冇 maskable、冇 og-image；iOS 主畫面係白板、WhatsApp／FB 分享冇預覽圖。
- 修正：`public/icons/` 九檔（favicon.ico 16/32/48、favicon-16/32、apple-touch-icon 180、icon-192/512、icon-maskable-192/512 取中央 78% 於 66% 安全區、og-image 1200×630），全部 PNG/ICO、減色量化、首碼驗證（合共 232 KB ≤ 260 KB）、16×16 手繪三層（天／金日／地）；`index.html` 掛齊 5 link ＋ theme-color；尺寸入測試自動守。
